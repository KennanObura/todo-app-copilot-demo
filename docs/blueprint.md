# **App Name**: TaskMaster

## Core Features:

- ToDo Form: Form to create and edit ToDo items, including fields for task description.
- ToDo Table: Display ToDo items in a table format, with columns for task description and actions (edit, delete).
- Simple Productivity Dashboard: Showing past stats on Todo finished and not finished in chat
- ToDo Management: Functionality to add, update, and delete ToDo items in memory. Does not use any persistent database.

## Style Guidelines:

- Primary color: Use Material UI's default primary color (typically a shade of blue or purple).
- Secondary color: Use Material UI's default secondary color (typically a shade of pink or teal).
- Accent: Yellow (#FFEB3B) for highlighting important actions like 'Add Task' or 'Save'.
- Use Material UI's Grid component for a responsive and structured layout.
- Employ Material UI icons for actions like edit, delete, and save.
